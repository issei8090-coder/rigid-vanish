# 剛体消失 — Rigid Vanish

**「剛体が世界から消えたら」** をテーマにした、ブラウザで遊ぶ物理シミュレーションゲームです。
物理エンジンや数値計算の外部ライブラリを15種類使っています。

▶ **プレイ:** https://issei8090-coder.github.io/rigid-vanish/

> ある朝、物理学の教科書から一行が消えた。
> 「質点系において、すべての任意の2質点間の距離が運動を通して一定であるもの」──剛体の定義である。

各章には剛性 κ のレベルがあります。κ=1 は教科書どおりの剛体、κ→0 は剛体が消えた世界です。
教科書の理論値と、剛体でなくなった物体の実測値を比べながらミッションに挑みます。
画面右側の「因果ログ」には、いま起きている力の伝わり方を、溝口ら(2016)の因果推論理論の原理番号つきで表示します。

## 章構成

| 章 | 内容 | 教科書の式 | ライブラリ |
|---|---|---|---|
| ハブ | 剛体の定義を触って確かめる（自由度 3 → 2N） | 3.4 自由度 | d3-force |
| 第1章 透過伝達性の喪失 | 押した力が、つながったブロックの反対側に届くまでの遅れ | 論文 原理4・5 | Rapier2D (WASM), Chart.js, Tone.js |
| 第2章 転がれない円柱 | 斜面を転がる円柱 ẍ = ⅔ g sinα と、柔らかいタイヤ | (3-59)〜(3-67) | Planck.js, Chart.js |
| 第3章 可逆振り子で g を測れ | 実体振り子・可逆振り子で g を測る | (3-37)〜(3-43) | p2.js, odex, Chart.js |
| 第4章 打撃の中心 | 撞く高さで滑らずに転がる条件が決まる | (3-74)〜(3-83) | Matter.js |
| 第5章 こまは倒れる | 歳差運動と、遠心力で裂けるこま | (3-84)〜(3-92) | three.js, cannon-es, odex |
| 第6章 豆腐を100Nで押せ | 反作用には根拠がいる（壁・豆腐・のれん） | 論文 3.2, 原理5・6 | three.js, Ammo.js (Bullet) |
| 終章 剛体ゼロ | 融けていく世界で最後の剛体を運ぶ | 3.1 剛体の定義 | LiquidFun (WASM), gpu.js |

## ローカルで遊ぶ

WASM と ES Modules を使うため、`file://` で開くのではなくローカルサーバ経由で開いてください。

```
start.bat                      # Windows: サーバ起動＋ブラウザを開く
python -m http.server 8765     # その他: http://127.0.0.1:8765/ を開く
```

ライブラリは CDN（jsDelivr / cdnjs）から読み込みます。インターネット接続が必要です。
