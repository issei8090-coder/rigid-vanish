軸の先が描く円（首ふり）あまりのびていないばねよくのびているばね

ミッション

回す速さ n を決めてこまを回し、10 秒間倒れずに立たせ続けよ。さらに、軸がぐるっと一周する首ふりの時間を目標 — 秒に合わせよ。

ゆっくりだと倒れる。やわらかいこまは、速く回しすぎると外に引っぱられてちぎれる。

やさしい解説

何が起きる？
速く回るこまは、少し傾いても倒れず、軸の先がゆっくり円を描きます。これを首ふり運動（歳差運動）といいます。
なぜ？
回っている物には「回転の勢い」があり、重力が倒そうとしても、その向きは横へずれるだけになるからです。勢いが大きいほど首ふりはゆっくりになります。
身近な例
走っている自転車は倒れにくい／回るコマ／ハンマー投げで回すほど手が外へ引っぱられる（やわらかいこまがちぎれるのと同じ）。

理論

首ふり1周の時間 T ∝ 回す速さ n

つまり、速く回すほど首ふりはゆっくりになる（2倍速く回せば、1周にかかる時間も2倍）。

ばねが引き戻す力 = ばね定数 × のび

つまり、外に引っぱられる力が強いほど、ばねは大きくのびないと支えきれない。のびすぎると切れる。

発展：教科書の式
L = I n (3-84) dL/dt = N (3-86) N = Mgh sinθ (3-89) T = 2π I n / (Mgh) (3-92)

L：回転の勢い（角運動量）、I：回りにくさ（慣性モーメント）、N：重力が倒そうとする回転の力（トルク）、h：支点から重心までの距離。

かたいこま（κ=1）は教科書の運動方程式を数値計算ライブラリ odex で解いて動かしている。やわらかいこま（κ<1）は cannon-es で小さな玉とばねを組み合わせて作った。
