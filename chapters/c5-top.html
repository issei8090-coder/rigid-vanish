理論（教科書 3.9 こまの歳差運動）

L = I n (3-84) dL/dt = N (3-86) N = ω × L (3-87) N = Mgh sinθ (3-89) ω' = Mgh / (I n) (3-91) T = 2π / ω' = 2π I n / (Mgh) (3-92)

剛体（κ=1）は重い対称こまのオイラー角 (θ, φ, ψ) の運動方程式を odex（Gragg–Bulirsch–Stoer 法）で解く。κ<1 のこまは cannon-es の粒子とばねで組み、剛体の仮定（2点間距離が一定）を外している。
